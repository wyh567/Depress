# 会话交接格式

> 每次会话结束时，按这个格式向用户输出。**不要超过 20 行。**

```markdown
## 本次会话

- 任务：T-xx <标题>
- 结果：DONE / BLOCKED / IN_PROGRESS

## 实际做了什么

- <改了哪些文件，各自改了什么。一行一个。>

## 验收实测

| 检查 | 命令 | 实际结果 |
|---|---|---|
| … | … | PASS / FAIL + 关键输出 |

## 需要用户决定的事

- <没有就写"无">

## 下一步

- 下一个任务：T-xx <标题>
- 开工前提：<有没有需要用户先做的事，比如 commit 批准>
```

## 填写纪律

- **不许**把"计划做什么"写成"做了什么"
- 验收表里的"实际结果"必须是**真跑命令得到的输出**，不是推测
- FAIL 的项不要粉饰，原样写出来
- 不要道歉、不要总结架构、不要复述任务文件内容
